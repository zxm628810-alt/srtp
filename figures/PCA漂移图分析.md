# PCA 漂移图分析

对应文件：

- `pca_by_batch.png`：按 Batch 着色的整体批次分布。
- `pca_early_vs_late_by_gas.png`：早期 Batch 1--3 与后期 Batch 8--10 的气体类别分布对比。
- `pca_gas_centroid_trajectories.png`：各气体类别中心在 Batch 1--10 间的移动轨迹。

## 1. 方法与正确解读范围

原始每个样本有 128 个传感器特征。先对每一维特征做标准化，再使用 PCA 投影到二维平面。PC1 解释 **53.52%** 的数据变化，PC2 解释 **15.04%**，两者合计 **68.56%**。因此这些图能够展示主要的传感器响应变化趋势。

PCA 在这里仅用于**描述和可视化**，不是分类模型的训练或测试步骤，也不改变此前严格滚动验证的结果。二维图中的靠近或重叠表示“在主要变化方向上更难分”，但不能单独证明两种气体一定被模型错分；最终仍应与混淆矩阵和逐类召回率结合解释。

## 2. `pca_by_batch.png`：不同批次如何漂移

- Batch 1、2 的点云范围最大，并有明显偏离主分布的样本；后续批次的点云更多聚集在 PC1 约 -20 到 10、PC2 约 -15 到 10 的区域。
- 各批次并没有完全分开，而是在主区域大量交叠。这表示传感器漂移不是简单的“每个新批次整体平移”，而是不同气体、浓度和传感器通道共同作用后的复杂分布变化。
- 后期 Batch 8--10 虽然总体更集中，但仍覆盖多个方向；这与滚动测试中 Batch 10 性能下降相一致：模型面对的不是一个与训练集完全无关的新团，而是发生了局部结构变化和类别边界移动的数据。

报告可用表述：**PCA 显示不同时间批次的传感器响应在主成分空间中发生系统性位置和形状变化，同时保留大量重叠区域，说明时序漂移具有渐进性和类别相关性。**

## 3. `pca_early_vs_late_by_gas.png`：哪些气体开始更接近

- 在早期 Batch 1--3 中，氨气（Ammonia）多位于较高 PC2 区域，与乙醛（Acetaldehyde）等类别存在明显方向差异；乙醛在较低 PC2 方向形成较显著延伸。
- 到后期 Batch 8--10，乙醇（Ethanol）、乙醛、丙酮（Acetone）和甲苯（Toluene）的主要点云更集中到 PC1 约 0--8、PC2 约 -3 到 4 的区域，视觉上出现更多重叠。
- 氨气仍有一部分样本处于较高 PC2 或较负 PC1 区域，保留一定区分度；但也有样本接近其他类别主区域，说明不能只依靠二维空间的“整体距离”判断其识别难度。
- 后期图中类别云团变紧、局部重叠增多，是“决策边界覆盖测试”应重点关注的区域：这些区域最可能对应模型置信度下降和类别混淆。

## 4. `pca_gas_centroid_trajectories.png`：类别中心的移动

每条彩色线连接同一种气体在不同 Batch 的二维平均位置；标注 `B1` 和 `B10` 分别表示该气体最早、最晚批次的中心。

- 氨气、乙烯（Ethylene）、甲苯的中心轨迹跨度较大，表明它们的传感器响应随批次发生了明显变化。
- 乙醛中心从早期较低 PC2 区域向后期接近 PC2=0 的区域移动；乙醇也集中在该邻近区域，提示二者在后期可能更难仅靠主要 PCA 方向区分。
- 二维类别中心距离中，Batch 1 最接近的一对是“乙醛--乙醇”（距离约 1.19）；Batch 10 最接近的一对变为“乙烯--甲苯”（约 0.86）。这说明潜在混淆关系会随时间改变，而不是固定不变。
- 以上距离只是在二维 PCA 平面上的描述性距离，不能替代 128 维空间距离或混淆矩阵；它的作用是帮助选择后续要重点检查的类别对。

## 5. 对后续实验的直接指导

1. 优先检查 Batch 10 中“乙烯--甲苯”、以及“乙醛--乙醇”的混淆矩阵条目和召回率。
2. 对于类中心移动明显的气体，测试滑动历史基线、分批归一化和更强的时序融合，而不是只使用一个原始 Batch 编号。
3. 在报告中将 PCA 图与滚动准确率/F1 曲线并列：前者解释“数据为什么变难”，后者量化“模型实际退化了多少”。
